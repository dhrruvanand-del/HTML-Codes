# 🏏 Hand Cricket Game

A modern, responsive, and interactive **Hand Cricket** web game built using **HTML5**, **JavaScript**, and styled with **Bootstrap 5**. Play classic hand cricket right in your browser with a sleek user interface!

---

## ✨ Features

* **Two Game Modes:** Choose whether you want to **Bat First** or **Bowl First**.
* **Complete Match Flow:** Full support for 1st innings targets, 2nd innings run chases, and dynamic wicket-detection mechanics.
* **Real-time Scoreboards:** Instant updates for your score, computer score, targets, and current innings status.
* **Fully Responsive UI:** Built with Bootstrap 5 cards, flexbox layouts, and custom interactive buttons that look great on both desktop and mobile devices.

---

## 🚀 How to Play

1. **Clone or Download** this repository to your local machine.
2. Locate the `hand_cricket.html` file.
3. **Double-click** the file to open it directly in any modern web browser (Chrome, Edge, Safari, Firefox).
4. Select your preferred starting mode (**Bat First** or **Bowl First**).
5. Tap the run buttons (**1 to 6**) to play your shot or bowl against the computer!
